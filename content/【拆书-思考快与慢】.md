## NAPKIN | 餐巾纸

### 公式

```
+----------------------------------------------------------+
|                                                          |
|   思考质量 = 系统2介入度 x (1 - 认知偏差系数)             |
|                                                          |
|   其中：                                                 |
|   系统2介入度 = 刻意调用理性分析的频率                   |
|   认知偏差系数 = 系统1主导时产生的系统性错误             |
|                                                          |
+----------------------------------------------------------+
```

我们的大脑有两条轨道：直觉快车道（系统1）和理性慢车道（系统2）。快车道省力但容易迷路，慢车道精准但费油。高手不是消灭快车道，而是知道什么时候换道。

### 一句话

人类决策的系统性偏差源于系统1（直觉）的自动运行和系统2（理性）的懒惰特性，理解这套机制是提升决策质量的第一步。

## ROUND 1: SKELETON | 骨架扫描

> "这本书在说什么"

**核心问题**: 人类的思维是如何运作的？为什么聪明人也会做出愚蠢的决策？

**核心答案**: 人类思维由两个系统构成——快速的直觉系统1和缓慢的理性系统2，系统1的高效运作带来系统性偏差，而系统2的懒惰特性使这些偏差难以被纠正。

**章节骨架**:
1. 双系统模型: 快与慢的两条思维轨道
2. 启发式与偏见: 系统1的三种主要捷径
3. 过度自信: 我们对自己判断力的盲目信任
4. 选择: 前景理论与决策的非理性本质
5. 两个自我: 体验自我与记忆自我的分离

**论证结构**: 归纳型 + 案例型
- 通过大量心理学实验归纳出思维模式
- 用具体案例展示每种认知偏差的运作

## ROUND 2: DISSECTION | 血肉解剖

> "凭什么这么说"

**论证链**:

```
[前提1] 人类思维可区分为自动化的直觉和刻意的理性
    |
    v
[前提2] 直觉系统(系统1)因其高效省力而默认主导日常决策
    |
    v
[前提3] 理性系统(系统2)因耗能巨大而倾向于懒惰
    |
    v
[前提4] 系统1依赖启发式(思维捷径)快速处理信息
    |
    v
[前提5] 启发式在多数情况下有效,但在特定场景产生系统性偏差
    |
    v
[结论] 认知偏差是人类思维的固有特性,非智力缺陷,需靠系统2主动干预来纠正
```

**关键证据**:
1. **琳达问题**: 描述"琳达是关心歧视和社会正义的年轻女性"后，85%的人认为她更可能是"女权主义银行柜员"而非"银行柜员"，违反概率基本法则（合取谬误）
2. **结肠镜实验**: 患者对检查的记忆主要由最痛时刻和结尾时刻决定，而非全程疼痛总量（峰终定律）
3. **损失厌恶实验**: 失去100元的痛苦约等于获得200元的快乐，损益敏感度比约为1:2

**隐形假设**:
- 假设1: 实验室环境中的决策行为可以推广到真实世界
- 假设2: 人类的认知结构在不同文化间具有普遍性
- 假设3: 系统1和系统2的功能划分可以解释大部分思维现象

**边界条件**:
- **何时失效1**: 高度专业领域——专家的直觉可能比理性分析更准确（如国际象棋大师的棋感）
- **何时失效2**: 时间紧急的生存情境——来不及调动系统2，必须依赖系统1的快速反应
- **何时失效3**: 极度熟悉的环境——系统1的启发式可能在特定情境下比系统2更可靠

## ROUND 3: SOUL | 灵魂提取

> "还能怎么用"

**作者盲点**:
1. **群体智慧**: 本书聚焦个体决策，但群体可能通过多样性抵消个体偏差
2. **人工智能**: 未深入探讨AI决策系统如何模拟或超越双系统模型
3. **可训练性**: 对"能否通过训练改善系统2的介入意愿"讨论不足
4. **文化差异**: 西方实验样本为主，东方文化下的认知偏差模式可能不同

**跨域映射**:
- 在 **计算机科学**，这叫 **"启发式算法 vs 精确算法"** —— 快速近似解与最优解的权衡
- 在 **经济学**，这叫 **"行为经济学 vs 古典经济学"** —— 理性人假设的挑战
- 在 **机器学习**，这叫 **"系统1直觉 = 模式识别"**，**"系统2推理 = 符号推理"**
- 在 **进化心理学**，这叫 **"快策略 vs 慢策略"** —— 生存繁殖的不同适应模式
- 在 **管理学**，这叫 **"直觉决策 vs 数据驱动决策"** —— 经验与分析的博弈
- 在 **投资领域**，这叫 **"情绪化交易 vs 量化策略"** —— 克服行为偏差的方法

**知识连接**:
- 《思考，快与慢》 + 《原则》(达利欧) → 如何建立系统化的决策流程
- 《思考，快与慢》 + 《黑天鹅》(塔勒布) → 认知偏差如何影响对极端事件的预测
- 《思考，快与慢》 + 《助推》(塞勒) → 如何设计选择架构来改善决策
- 《思考，快与慢》 + 《刻意练习》(艾利克森) → 如何训练系统2的主动介入

**行动触发**:
1. **重大决策前**: 强制启动"事前验尸"(Pre-mortem)——假设决策已失败，逆向分析可能原因
2. **投资决策**: 记录买入理由，设定卖出标准，用"外部意见"替代过度自信
3. **避免疲劳决策**: 饥饿、疲惫时不做重要决定（研究显示法官饭后保释批准率更高）
4. **质疑第一印象**: 刻意寻找反证，问"什么情况下我的判断是错的？"
5. **重构问题框架**: 用"存活率90%"而非"死亡率10%"来影响决策感知
