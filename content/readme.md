# 拆书笔记技能说明

## 什么是拆书？

拆书是一种将书籍内容系统化整理、提炼核心观点、转化为可执行知识的学习方法。我作为你的 AI 助手，可以帮助你高效完成拆书全过程。

---

## 深度拆书机 (ljg-xray-book)

基于 **Epiplexity 原理** 的专业拆书技能，通过三轮认知压缩最大化提取书籍中的可学习结构。

### 核心哲学

```
+------------------------------------------------------------------+
|  传统观点：信息是数据的固有属性                                    |
|  Epiplexity：信息是相对的，取决于观察者的"认知算力"                |
+------------------------------------------------------------------+
|                                                                   |
|  同一本书 = 可学习的结构(S) + 不可学习的噪声(N)                   |
|                                                                   |
|  关键洞见：S 和 N 的切割线位置，取决于你投入多少算力               |
|                                                                   |
|  算力低 → 大部分内容看起来是"噪声"                                |
|  算力高 → 更多内容变成"可学习的结构"                              |
|                                                                   |
+------------------------------------------------------------------+
```

### 使用方法

```
/ljg-xray-book 《思考，快与慢》
/ljg-xray-book Atomic Habits
/ljg-xray-book {书籍内容}
```

### 三轮认知压缩

| 轮次 | 名称 | 目标 | 核心问题 |
|-----|------|------|---------|
| 第一轮 | 骨架扫描 | 建立全局结构 | 这本书在说什么？ |
| 第二轮 | 血肉解剖 | 理解论证链条 | 凭什么这么说？ |
| 第三轮 | 灵魂提取 | 超越作者 | 还能怎么用？ |

### 输出内容

生成的 Org-mode 报告包含：

- **NAPKIN (餐巾纸)** — 极限压缩：公式 + 一句话 + ASCII 草图
- **ROUND 1: SKELETON** — 骨架扫描：核心问题、核心答案、章节骨架、论证结构
- **ROUND 2: DISSECTION** — 血肉解剖：论证链、关键证据、隐形假设、边界条件
- **ROUND 3: SOUL** — 灵魂提取：作者盲点、跨域映射、知识连接、行动触发
- **STRUCTURE MAP** — ASCII 全书结构图

## 通用拆书能力

### 1. 内容提取
- 从 PDF、EPUB、DOCX 等格式提取书籍内容
- 从网页链接抓取文章并清理格式
- 从 YouTube 视频提取字幕/文字稿

### 2. 知识结构化
- 自动识别书籍框架和章节逻辑
- 提取核心概念、定义、公式
- 梳理作者论证思路
- 建立知识点之间的关联

### 3. 笔记生成
- 生成符合 Obsidian 格式的 Markdown 笔记
- 自动添加 YAML front matter（标签、日期、来源）
- 生成双向链接便于知识网络构建
- 提取金句和可引用内容

### 4. 行动转化
- 将书中观点转化为具体行动清单
- 生成"如何应用到工作/生活"的思考题
- 制作复习卡片和记忆要点

## 使用方法

### 方式一：深度拆书 (推荐)

```
/ljg-xray-book 《书名》
```

### 方式二：直接提供内容

```
请帮我拆解以下内容：
[粘贴书籍段落或文章内容]
```

### 方式三：提供文件路径

```
请帮我拆解 /path/to/book.pdf
```

### 方式四：提供网页链接

```
请帮我拆解这篇文章：https://example.com/article
```

### 方式五：提供 YouTube 视频

```
请帮我拆解这个视频的内容：https://youtube.com/watch?v=xxx
```

| 剪贴板内容 | 直接粘贴 | 粘贴内容后说"请拆解" |

## 最佳实践

1. **明确目的**：告诉我想从这本书获得什么（快速了解/深度学习/实践应用）
2. **分批处理**：长篇内容可以分章节拆解
3. **及时互动**：对不理解的内容可以追问
4. **结合实践**：要求生成具体的行动清单
