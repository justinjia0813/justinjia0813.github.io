## NAPKIN | 餐巾纸

### 公式

```
+----------------------------------------------------------+
|                                                          |
|   表达 = 结论^论点(论据1, 论据2, 论据3)                    |
|                                                          |
|   先说结论，再给3个理由，层层支撑                          |
|                                                          |
+----------------------------------------------------------+
```

公式含义：有效表达的本质是一个金字塔结构——顶端是结论，中间是支撑论点，底部是具体论据。幂运算符号(^)表示论点对结论的"支撑力"。

### 一句话

**先说结论，再给理由，层层支撑，让读者用最小认知成本理解你的观点。**

### 草图

```
                    +------------+
                    |   结论     |  <-- 最先说
                    +-----+------+
                          |
          +---------------+---------------+
          |               |               |
    +-----v-----+   +-----v-----+   +-----v-----+
    |  论点1    |   |  论点2    |   |  论点3    |  <-- 再说3个理由
    +-----+-----+   +-----+-----+   +-----+-----+
          |               |               |
    +-----+-----+   +-----+-----+   +-----+-----+
    |论据|论据|   |论据|论据|   |论据|论据|  <-- 最后是细节
    +-----------+   +-----------+   +-----------+

    四大原则：结论先行 | 以上统下 | 归类分组 | 逻辑递进
```

## ROUND 1: SKELETON | 骨架扫描

> "这本书在说什么"

**核心问题**: 如何让思考清晰、表达有力？

**核心答案**: 用金字塔结构组织思想——结论先行，以上统下，让读者理解成本最低。

**章节骨架**:
1. 表达的逻辑: 金字塔结构基本原理
2. 思考的逻辑: 纵向关系与横向关系
3. 解决问题: 序言与SCQA框架
4. 演示的逻辑: PPT与文档呈现
5. 附录: 实践练习与案例

**论证结构**: 归纳+演绎混合型
- 演绎：从认知科学原理推导出金字塔结构的必要性
- 归纳：通过大量商业案例验证方法的有效性

## ROUND 2: DISSECTION | 血肉解剖

> "凭什么这么说"

### 论证链

```
[大脑规律]          [结构设计]          [表达策略]          [最终效果]
+----------+        +----------+        +----------+        +----------+
| 大脑自动 |  --->  | 金字塔顺 |  --->  | 逆序表达 |  --->  | 读者理解 |
| 归类分组 |        | 应认知规 |        | 先结论后 |        | 成本最小 |
| 有序记忆 |        | 律       |        | 论证     |        | 化       |
+----------+        +----------+        +----------+        +----------+
```

### 关键证据

1. **麦肯锡40年咨询实践验证**：成为公司核心培训教材
2. **学术界认可**：哈佛、斯坦福等顶级商学院采用
3. **实战效果**：SCQA框架在商业汇报中的高效应用

### 隐形假设

- 假设1: 听众认知资源有限，无法处理复杂无序信息
- 假设2: "逻辑清晰"等于"有效沟通"
- 假设3: 结论先行适用于绝大多数沟通场景
- 假设4: 读者更关心"结论"而非"过程"

### 边界条件

- **创意发散场景**：头脑风暴需要先发散再收敛，结论最后才浮现
- **情感共鸣场景**：讲故事、演讲需要铺垫悬念，过早给出结论破坏体验
- **探索性对话**：双方共同发现答案的过程比答案本身更重要
- **文化差异**：东方文化偏好含蓄表达，直接结论可能显得冒犯

## ROUND 3: SOUL | 灵魂提取

> "还能怎么用"

### 作者盲点

- 过度强调逻辑可能抑制创意和直觉判断
- 未充分考虑跨文化沟通差异（东方文化偏好含蓄）
- 忽视了"何时打破规则"的讨论
- 假设读者都是理性决策者，忽视情感因素

### 跨域映射

| 领域 | 概念 |
|------|------|
| 软件工程 | 抽象层次原则（高层模块不应依赖低层模块）|
| 编程 | 函数调用栈（main → function → subroutine）|
| 管理学 | OKR目标分解（Objective → Key Results → Tasks）|
| 认知科学 | 认知负荷理论（减少外在认知负荷）|
| 金字塔原理 | MECE原则（相互独立，完全穷尽）|

### 知识连接

- **《思考快与慢》**的系统2思维：金字塔结构降低系统2的认知负担
- **《第一性原理》**：从结论出发是"从根本原因出发"的表达版
- **《非暴力沟通》**：结构化表达减少误解，提升沟通效率
- **写作领域**：与"倒金字塔结构"新闻写作异曲同工

### 行动触发

1. **/沟通前/**：先问自己"我的结论是什么？"用一句话概括
2. **/开场时/**：用SCQA框架组织（情境-冲突-问题-答案）
3. **/论证时/**：检查论据是否MECE（相互独立，完全穷尽）
4. **/练习时/**：每天练习30秒电梯演讲，先说结论再展开
5. **/复盘时/**：检查表达是否符合四大原则（结论先行、以上统下、归类分组、逻辑递进）

## APPENDIX | 附录

### SCQA框架详解

| 要素 | 含义 | 示例 |
|------|------|------|
| S | Situation 情境 | 公司业务稳定增长 |
| C | Complication 冲突/问题 | 竞争对手推出新产品 |
| Q | Question 疑问 | 我们如何应对？ |
| A | Answer 答案/方案 | 建议加速产品迭代 |

### 常见错误 vs 正确做法

| 错误做法 | 正确做法 |
|----------|----------|
| 先说背景和过程，最后才说结论 | 开头就说结论，再展开理由 |
| 信息杂乱，想到哪说到哪 | 归类分组，逻辑清晰 |
| 每个观点都是独立的，没有层级 | 以上统下，层层支撑 |
| 论据之间有重叠或有遗漏 | 检查MECE，相互独立完全穷尽 |
