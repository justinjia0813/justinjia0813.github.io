摘要 · SUMMARYDATA · MODEL · FLYWHEEL · LAB摘要

核心判断AI4M（AI for Materials，AI 驱动材料研发）的竞争正在从“谁的模型更好”转向“谁拥有带标签的真实数据”。公开数据和计算数据正在变成人人都有的底座，通用原子模型正在被开源拉平，调度用的大模型会被前沿实验室拿走。可以留存的价值在三处：私有数据校准过的专用模型、承载领域规则与验证器的 harness，以及能低成本、高保真地生产带过程、带失败数据的自主实验室。

本文是一份学习笔记，整理围绕五个问题的讨论：

  1. 模型怎么训练：pre-training、mid-training、post-training 各学什么，壁垒分别在哪。
  2. 数据怎么分类：用三条正交轴定位（来源、组织程度、归属），再用五个维度打分。
  3. 数据放在哪一层：哪些数据训进模型权重，哪些放进 agent harness；客户私有数据放在哪。
  4. 技术路线：怎么看“大模型调度 + 小模型专精”。
  5. 飞轮与自主实验室：结果归客户时，过程数据还有没有用；自主实验室的壁垒究竟在哪里。

十条要点

  1. mid-training 仍在学知识，post-training 在学行为。 数据壁垒主要体现在 mid-training，验证器壁垒主要体现在 post-training。
  2. 数据用三条正交轴定位： 来源（文献、计算、实验、生产、专家、交互轨迹）、组织程度（非结构化到审核数据库）、归属（公开、付费、企业私有、自产）。“结构化数据库”是治理形态，不是来源；企业研发数据属于实验（C2），不属于生产（D）。
  3. 数据质量看五个维度： 保真度、是否含过程、是否含失败、标签形态、能否主动生成。
  4. 越“统计”的数据越贡献模型，越“程序性”的数据越贡献 agent。 计算数据主要喂原子模型，专家知识和轨迹主要喂 agent。
  5. 放权重还是放 harness，由五条判据决定： 规模、稳定性、延迟、精确性，以及权属。客户数据一旦训进共享权重就撤不出来了。
  6. “大模型调度 + 小模型专精”的方向是对的，但这是“通用与专用”之分，不是“大与小”之分。 而且价值不在调度层。
  7. CRO 模式下，过程数据在法律上通常归客户。 CRO 物理上掌握的数据最全，但能合法用于训练的很少。
  8. 结果归客户时，材料模型的飞轮转不起来，实验室与 agent 的飞轮转得起来。 后者是高效率 CRO 的壁垒，估值应对标 CRO。
  9. 最有价值的数据，是“真实任务 × 受控过程”：把客户的真实任务放进自己的自主实验室里跑。最值得争取的单项数据，是客户回传的下游验证结果。
  10. 自主实验室有壁垒，但不在机械臂上。 壁垒在长尾操作、可靠性、表征保真和放大衔接，最终体现为复利积累的私有数据。

第一章 · CHAPTERDATA · MODEL · FLYWHEEL · LAB模型怎么训练：学知识，还是学行为

1.1 三个阶段

Pre-training（预训练）Mid-training（中期训练）Post-training（后训练）
学什么通用知识和语言能力补强特定能力：数学、代码、长上下文、推理、垂直领域行为：听懂指令、格式、偏好、安全、推理策略、工具使用
数据万亿 token 级的网页、书、代码，量大、质量参差千亿 token 级的高质量或领域数据，常混入合成数据万到百万条的示范问答、偏好对比，或可自动判分的任务
目标函数预测下一个 token仍是预测下一个 token监督微调 SFT；偏好优化（RLHF、DPO）；可验证奖励强化学习 RLVR
改变的是模型“知道什么”模型“知道什么”，重心偏向目标领域模型“怎么做”

1.2 为什么会单独分出 mid-training

  • 学习率退火：在预训练尾声把学习率降下来，同时喂最好的数据，效果比一直喂普通数据好很多。Llama 3 称之为 annealing，AI2 的 OLMo 2 直接称为 mid-training。
  • 长上下文扩展：从 8K 拉长到 128K 或更长，需要单独用长文档继续训练。
  • 为后训练铺路：先喂大量推理链、数学和代码，强化学习阶段模型才有“可以被强化的行为”。一个常见观察是：RL 更擅长把已有能力“挖出来”，不太擅长凭空创造能力。
  • 领域继续预训练（Continued Pre-training，CPT）：拿通用底座模型，用医学、法律、化学语料继续训练，也属于 mid-training。

1.3 放到 AI4M 里

阶段材料科学版本壁垒在哪
Pre-training使用通用底座模型（自己训练的公司很少）算力与资金；创业公司一般不碰
Mid-training用文献、专利、实验记录，以及晶体结构和分子的文本化表示（CIF、SMILES）继续训练私有领域数据，尤其是过程数据和失败实验
Post-training教模型调用 DFT（密度泛函理论）和 MLIP（机器学习原子间势）、规划实验；用模拟器或自主实验室的结果做 RL 奖励验证器：能否便宜、快速、可信地判断“这个建议对不对”

MLIP 的“大数据预训练 + 在目标体系上微调”，结构上更接近“预训练 + 领域 mid-training”：它回归的是能量和力，没有对话式的后训练。

投资含义一家公司说自己在做“材料大模型”时，要问清楚它做到了哪一步。只做了 SFT，说明壁垒很薄；做了私有数据的 mid-training，要查数据的权属和规模；做了 RL，要查奖励由谁给、准确度如何，以及有没有奖励投机（reward hacking）。

第二章 · CHAPTERDATA · MODEL · FLYWHEEL · LAB数据：三条正交轴

2.1 三条正交轴

任何一条数据，都可以用三个互相独立的问题来定位：它从哪里来，加工到了什么程度，归谁所有。

轴回答的问题取值决定什么
轴一 · 来源谁、用什么机制产生的A 文献与专利、B 计算、C 实验（C1 自主 / C2 人工 / C3 表征原始信号）、D 生产、E 专家、F 交互轨迹数据里本来有什么信息：有没有过程、有没有失败、离真实任务多近
轴二 · 组织程度加工到了什么程度L1 非结构化 → L2 半结构化 → L3 结构化 → L4 审核数据库用起来要花多少治理成本
轴三 · 归属谁能用它训练公开、付费或授权、企业私有、AI 公司自产能不能进共享权重、能不能形成自己的资产

两处容易混淆的地方：

  • 结构化数据库属于组织程度，不属于来源。 ICSD、CSD 来自文献里的实验结构，Materials Project 来自高通量 DFT，NIST 性质数据来自测量加专家评审。同一条晶体结构，写在论文里是 L1，收进 ICSD 就到了 L4，来源始终没有变。
  • “工业数据”描述的是归属，不是来源。 企业研发中心做的实验，产生机制和学术实验室相同，属于实验；只有产线运行时产生的数据才属于生产。

2.2 一张图看懂：数据坐标系

三条轴都是离散的，所以不用三维立方体，而是把来源和组织程度摆成矩阵的行和列，归属用颜色编码。“数据库”画成一条从左向右的箭头，表示它是一个治理过程。

三个读图要点：

  1. 行决定上限，列决定成本。 行是类别，不是排名：每一类来源带来的是不同种类的信息（矩阵右侧四列给出了各行的信息构成），所以不存在“越往下越好”。来源之间是互补的，比如用计算数据做先验、用自主实验校准、用生产数据验证放大。列则是有序的：越往右，用起来越省事，但信息量并不增加。治理能把 L1 理顺成 L3，却补不出来源里本来没有的信息。文献里本来没有失败实验，抽取得再精细也不会有。
  2. 右上角常被高估，左下角常被低估。 公开的审核数据库（Materials Project、ICSD）质量最高，但人人都有，所以不构成壁垒。企业的交接班记录、失效报告、口头经验处在 L1，治理成本最高，却是别人拿不到的。很多公司卖的其实是“把 L1 治理成 L3”的能力，这属于数据工程服务。
  3. 自主实验室的隐性优势在于“生来就在 L3”。 C1 和 F 的数据产生时就是结构化的，而且归 AI 公司所有。这是唯一一块同时满足“信息完整、无需治理、归自己”的区域。

2.3 企业研发数据算哪一类

在这套框架里，企业研发中心的实验数据属于 C2，不属于 D。D 特指生产侧：量产工艺、批次、良率、现场失效。

两者的分界可以用研发阶段来看：

  • C2 覆盖发现、开发、放大三段；D 覆盖量产，在中试阶段与 C2 交界。
  • 中试数据最稀缺。 它同时带有配方、工艺和放大后的真实性能，几乎只存在于企业内部，自主实验室也测不出来。
  • 所以“企业私有数据”的准确说法是：私有的 C2 + D + E。第三章第 4 节讨论的客户私有研发数据，就是这个口径。

2.5 再加五个质量维度

三条轴用来给数据定位，下面五个维度用来给数据打分：

  1. 保真度：计算级别或测量精度有多高，与真实世界差多远。
  2. 是否含过程参数：只有结果，还是也记录了“怎么得到这个结果”。
  3. 是否含失败：负样本决定模型能否知道“哪里不行”。
  4. 标签形态：标量、谱图、图像还是时序，决定能用什么模型。
  5. 能否主动生成：B、C1、F 可以按需生产，属于“主动数据”；其余只能收集。主动数据才能支撑闭环和因果推断，因为只有它可以按照模型的不确定性去设计下一批实验。
判断数据的价值，等于它对一个决策带来的信息增量，除以获取它的成本。来源决定分子的上限，组织程度决定分母，归属决定这份价值归谁。

第三章 · CHAPTERDATA · MODEL · FLYWHEEL · LAB数据放在技术栈的哪一层

3.1 六层技术栈

层内容
L1 通用大模型预训练、mid-training、post-training
L2 领域基础模型机器学习原子间势 MLIP、性质预测、生成模型、谱图解析
L3 项目级代理模型高斯过程、贝叶斯优化、小样本微调，在线更新
L4 Agent harness检索增强 RAG、工具库、SOP 与技能、硬约束、规划器、验证器
L5 轨迹训练用轨迹做监督微调、偏好学习、强化学习，优化 agent 策略
L6 执行层实验室控制、调度、数据采集

3.2 各类数据的贡献

数据主要放在对模型能力的贡献对 agent 能力的贡献
A 文献L1 mid-training；L4 检索中等：给出先验和词汇，但定量不可靠高：让 agent “懂行”、会拆解任务
B 计算L2最高（原子尺度模型几乎全靠它）低，只是作为工具被调用
审核数据库（L4）L2 微调和校准；基准测试高：用来把模型拉回真实世界低
C1 自主实验L3 在线更新；积累够了再回流 L2对“最后一公里”的精度最关键中等：校准工具可信度
C2 历史实验记录治理后进 L3 或 L4 检索中等：噪声大，缺失败实验中等
C3 表征原始数据L2 谱图与图像模型高：解决“测量瓶颈”中等
D 生产数据L3 客户私有模型；L4 因果或工艺规则对放大生产和良率最关键，对发现新材料弱中等
E 专家知识L4 为主；积累到一定量后进 L5 做奖励或偏好低最高：规划、剪枝、排错
F 轨迹L5间接长期最高，也是飞轮本身

3.3 放进权重，还是放进 harness

更适合训进权重更适合放进 harness
量大、是统计规律量小、是显式规则或流程
稳定，不常变经常更新（新设备、新 SOP、新客户）
内循环里要低延迟地大量调用要可审计、可解释
允许有一定误差必须精确（安全约束、危化品规则、设备限制）
权属清楚、可以共享属于客户、需要隔离或可撤回

专家数据可以再细分三层：

  • 可以写成规则的部分（禁忌、安全要求、设备能力边界）→ 放进 harness 的硬约束和技能；
  • 可以写成流程的部分（怎么排错、先做什么表征）→ 放进 harness 的规划模板；
  • 只能“一眼看出来”的判断（哪个候选更有希望）→ 收集成成对偏好数据，训练奖励模型，这部分进权重。

专家数据先放进 harness 还有一个好处：harness 会自动产生 F 类轨迹数据，等于把专家知识变成可规模化的训练数据。这是比“请专家标注”更便宜的路径。

3.4 客户私有研发数据放在哪里

客户的私有研发数据对应 C2、D、E 三类，它们在技术栈里的位置由归属决定：

层能不能放方式
L1 通用大模型 / L2 共享领域模型默认不放训进共享权重就撤不出来了，还可能被其他客户“问出来”
L2 的客户专属微调可以每个客户一个适配器（如 LoRA）或专属模型，底座共享、增量独占
L3 项目级代理模型主战场历史数据用作先验，省掉冷启动
L4 租户隔离的 harness主战场客户的 SOP、配方库、规则放进专属检索库和约束库，可审计、可删除
本地部署客户自己放数据不出厂；AI 公司最多拿到模型更新或统计量（联邦学习），且需合同允许
结论客户数据在技术上最有用的位置，恰好也是法律上最容易隔离的位置——L3 和 L4。它帮客户把项目做快，但不会自动变成 AI 公司的资产。

第四章 · CHAPTERDATA · MODEL · FLYWHEEL · LAB技术路线：怎么看“大模型调度 + 小模型专精”

方向认同，但有五处修正。

  1. 不是“大与小”，而是“通用与专用、语言与物理”。 专用模型不是因为小才好，而是因为模态不同：三维结构、等变性、能量守恒，用语言 token 表达得很差。专用模型也在变大（Meta 的 UMA、微软的 MatterSim、Orb），MLIP 同样有规模定律。
  2. 边界会移动。 前沿大模型正在吃掉越来越多“专用”任务，比如逆合成、谱图解读、文献抽取。留得住的是需要物理精度或私有数据的任务。
  3. 真正的难点在接口，而不在调度本身。 大模型调用工具时，要知道工具什么时候超出了适用范围、不确定度有多大、单位和条件是否匹配。专用模型如果不输出校准好的不确定度，调度层再聪明也会被错误的工具带偏。
  4. 调度层的价值会被前沿实验室拿走。 通用大模型应该租用、可以替换；力气应该花在 harness 和专用模型上。
  5. 专用模型内部也要分层。 通用原子模型正在被开源拉平；真正留得住价值的，是用私有实验数据校准过的微调模型和项目级代理模型。

一个更完整的版本：

  1. 租用通用大模型，或用开源底座加少量微调；
  2. 由 harness 承载领域规则和验证器；
  3. 开源 L2 模型用自有数据校准；
  4. 由 L3 代理模型驱动自主实验室闭环；
  5. 轨迹回流到 L5。

壁垒在下半段。

投资含义警惕壁垒只是“我们用化学论文微调了一个 7B 模型”的公司。要看的是：专用模型的不确定度是否校准过、验证器是否可信、闭环是否真的在产生公司自己拥有的数据。

第五章 · CHAPTERDATA · MODEL · FLYWHEEL · LAB飞轮：谁拥有标签，飞轮就在谁那里

5.1 CRO 模式下的数据归属

CRO（Contract Research Organization，合同研究组织）亲手做实验，所以物理上掌握的数据最全：反应条件、失败尝试、原始谱图、批次记录、偏差。符合 GLP、GMP 的项目，还必须按法规归档原始记录。

但典型的主服务协议（MSA）并不按“过程 / 结果”划分，而按“客户项目成果”与“CRO 背景能力”划分：

类别包含什么归属
前景成果 / 工作成果（Work Product）交付的化合物和报告，以及该项目产生的全部数据（含原始数据和过程记录）客户
背景知识产权与通用知识CRO 原有的平台、方法、通用工艺改进、人员经验CRO
灰色地带去标识聚合后的统计规律、人员习得的经验取决于合同写法

5.2 “结果”其实分两类

交付结果运营结果
内容目标分子或配方是什么、最终性能、最优工艺、报告这一步能不能自动执行、是否堵针或结块、有没有偏差、耗时、成本、人工干预次数、调度顺序
对客户的价值全部几乎为零
通常归属客户可以谈成归 AI 公司（写成“运营元数据”保留条款）
能训练什么材料性质模型实验室模型与 agent 模型

灰色地带在过程中的分析数据：比如反应中途的液相色谱、中间体收率。客户多半会把它们算作结果，这是谈判的焦点。

5.3 没有交付结果，还能学到什么

学什么标签从哪来放在哪一层价值
可执行性：这个方案在我的设备上能不能跑通运营结果L6 + L4高
异常检测与失败预警运营结果L6高
调度与成本模型运营结果L6中等
agent 的规划策略方案有没有被人改、有没有跑通L5高
优化策略的元学习收敛速度本身（不含最优解是什么）L3 的超参数和先验中等
谱图与时序的表示学习自监督，不需要标签L2 表征模型中等（仍须约定可以使用）
需求地图不需要标签：客户在解决什么问题、面对什么约束战略与产品层高（常被低估）
结构到性能的映射缺少标签L2无

5.4 两个飞轮

  • 材料模型的飞轮转不起来。 缺少标签，客户项目再多，模型在材料科学上也不会变得更聪明。
  • 实验室与 agent 的飞轮转得起来。 项目越多，可执行率越高、失败越少、方案被人修改得越少、单个数据点越便宜、新体系上手越快。
  • 这就是“高效率 CRO”的壁垒，和药明当年的路径一致，只是经验存在系统里而不是人脑里。它很真实，但估值天花板是 CRO 的倍数，而不是数据平台的倍数。

5.5 两条轴：任务真实性 × 过程受控

维度② 客户历史数据③ 自有实验室的探索数据
目标是否相关高：真实的性能指标和约束可能偏离市场需求，只是在优化代理指标
下游标签有：放大、器件、可靠性通常只有实验室能测的指标
过程是否完整低：只记设定值，很多变量没记高：记录实际值、时序和设备日志
失败样本很少，存在幸存者偏差全部保留
因果可识别性差：专家选的条件并不随机，变量间混杂严重好：实验经过设计和主动扰动
一致性不同操作员、不同仪器、不同年份同一套设备和协议
主要风险模型学到专家的习惯，而不是物理规律在自己定义的题目上“自嗨”

虚拟任务的真正风险，在于奖励函数是自己定的。 就像用 DFT 做 RL 奖励会导致奖励投机一样，用“实验室能测的指标”做目标，也会让整个闭环去优化一个代理指标。真实任务的价值就在于：奖励是市场给的。

5.6 想要材料模型的飞轮，必须有第二台发动机

路径做法代价
自主选题用需求地图指导自己跑实验，标签归自己烧钱，而且仍是虚拟任务
自有产品做垂直材料，自己卖材料，结果归自己需要化工和市场能力，周期长
延迟解密合同约定专利申请后或 N 年后，结果可以去标识使用数据有时滞，客户不一定同意
共有 IP用价格或共同开发换取结果的使用权收入下降，恐怕只有中小客户肯签
公共体系在非保密体系（学术合作、政府项目、开放基准）上积累带标签数据商业相关性有限
最值得争取的单项数据客户拿走样品后，在自己的产线和器件里测出的下游结果（是否通过验证、器件性能、可靠性）。这是自主实验室永远测不到的标签，CRO 通常也拿不到。哪怕只回传“通过 / 不通过”，价值也可能高于一大堆过程数据。

第六章 · CHAPTERDATA · MODEL · FLYWHEEL · LAB自主实验室：壁垒不在机械臂上

机械臂、移液工作站、反应釜都能买到，有钱的对手一两年内就能搭出同样的硬件。壁垒在下面七处：

壁垒为什么难怎么验证
1. 长尾操作的覆盖度材料合成很“脏”：粉体加料、高粘液体、过滤、后处理、无水无氧、高温烧结、成膜。每补上一种操作都需要大量工程试错真实工作流里可以无人值守的步骤占多少
2. 可靠性与异常恢复闭环的价值来自无人值守地长时间运行，堵针、挂壁、误差累积都会让它停下来开机率、平均多久故障一次、一周人工干预几次
3. 表征与数据保真度合成很快，测量很慢。A-Lab（《Nature》2023）之所以受质疑，就是 XRD 物相识别这一环出了问题在线表征的比例、重复实验的变异系数 CV、自动判读与人工判读的一致率
4. 数据标准化与可追溯同样是实验数据，有完整元数据和来源记录的，才能直接用来训练模型能否从一个性能值回溯到原料批号和设备日志
5. 调度软件与指令层要把“化学意图”自动翻译成“设备动作”，还要做硬件抽象新的化学体系要多久才能跑起来
6. 放大生产的衔接毫克级的最优解到公斤级经常失效；能衔接的，才接得住工业客户毫克级结果在公斤级上的复现率
7. 复利积累的数据前六项做好的结果，是私有数据随时间复利增长。这是唯一不能靠钱快速复制的东西第 N 个项目是否明显比第一个快

两个结构性判断：

  • 专用实验室比通用实验室更容易建立壁垒。 专门做电解液配方或光刻胶配方的实验室，可以把覆盖度、可靠性和表征都做到极致；“什么材料都能做”的实验室，往往哪里都不够深。
  • 卖实验室的公司和用实验室的公司是两种生意。 卖硬件的公司拼交付和成本，壁垒接近系统集成商；用实验室产生数据和材料的公司，壁垒才是第 7 项。把实验室本地部署卖给客户，等于把第 7 项也一起卖掉了。
