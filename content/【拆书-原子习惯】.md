## NAPKIN | 餐巾纸

### 公式

```
+----------------------------------------------------------+
|                                                          |
|   习惯 = 提示 + 渴求 + 反应 + 奖励                        |
|                                                          |
|   成长 = (1 + 1%)^365 = 37倍                             |
|                                                          |
+----------------------------------------------------------+
```

习惯遵循四阶段回路：提示触发渴求，渴求驱动反应，反应产生奖励，奖励强化习惯。
每天进步1%，一年后将提升37倍——微小改变的复利效应。

### 一句话

成功不是一次性的巨大改变，而是无数微小改进的累积；你不会达到目标水平，只会落到系统水平。

## ROUND 1: SKELETON | 骨架扫描

> "这本书在说什么"

**核心问题**: 为什么有些人能持续改变行为，而大多数人却反复失败？

**核心答案**: 因为他们专注于设计"系统"而非追求"目标"——通过身份认同的改变和行为设计四定律，让好习惯自动发生。

**章节骨架**:

*第一部分：基本原理*
1. 微小习惯的惊人力量: 1%改进的复利效应
2. 习惯塑造身份: 成为谁比达成什么更重要
3. 习惯形成的四步: 提示-渴求-反应-奖励回路

*第二部分：第一定律*
4. 让提示显而易见: 环境设计+执行意图
5. 习惯叠加: 在现有习惯后追加新习惯

*第三部分：第二定律*
6. 让习惯有吸引力: 诱惑绑定+群体效应
7. 重新设计渴求: 改变对习惯的预期

*第四部分：第三定律*
8. 让习惯简便易行: 两分钟法则+环境设计
9. 减少阻力: 让好习惯成为最省力的选择

*第五部分：第四定律*
10. 让习惯令人愉悦: 即时奖励+追踪进度
11. 保持习惯: 永不中断法则

*第六部分：高级战术*
12. 基因与习惯: 找到适合天性的领域
13. 维持动力: 在厌倦时坚持下去

**论证结构**: 归纳型 + 案例型（用大量真实案例和实验数据支撑）

## ROUND 2: DISSECTION | 血肉解剖

> "凭什么这么说"

**论证链**:

```
目标导向失败 ──→ 因为目标只是方向，不保证执行
       │
       ▼
系统导向成功 ──→ 因为系统决定长期行为模式
       │
       ▼
身份改变是核心 ──→ 每个行动都是对身份的投票
       │
       ▼
习惯四阶段 ──→ 提示→渴求→反应→奖励
       │
       ▼
行为四定律 ──→ 针对每阶段的设计策略
       │
       ▼
复利效应显现 ──→ 突破潜能蓄积期后质变
```

**关键证据**:

1. **英国自行车队案例**: 2003年以前从未获得环法冠军，Dave Brailsford通过"边际收益聚合"策略（每个环节改进1%），十年内获得178个世界冠军和5次环法冠军。

2. **1%复利计算**: 每天进步1% → (1.01)^365 = 37.78倍；每天退步1% → (0.99)^365 = 0.03倍。

3. **习惯形成实验**: 伦敦大学研究发现，新习惯自动化平均需要66天，而非普遍认为的21天。

**隐形假设**:

- 假设1: 读者有稳定的生活环境，能够控制环境设计
- 假设2: 读者的阻碍主要来自行为层面，而非严重的心理健康问题
- 假设3: "进步"是线性的正向追求，不涉及价值观冲突
- 假设4: 小习惯的累积一定会产生质变（忽略了临界点的不确定性）

**边界条件**:

- 当环境完全不可控时（如监狱、战乱），系统设计难以实施
- 对于成瘾性行为（药物、酒精），仅靠四定律可能不足
- 在需要创意爆发而非稳定输出的领域，过度系统化可能抑制创新
- 当目标本身就是享受过程时，"系统化"可能破坏乐趣

## ROUND 3: SOUL | 灵魂提取

> "还能怎么用"

**作者盲点**:

1. **系统性不平等的忽视**: 不是每个人都有"安静的空间"或"健身房会员"，环境设计需要资源
2. **集体习惯的缺失**: 过于关注个人，忽略了组织/社会层面的习惯养成
3. **负向习惯的复杂性**: 某些坏习惯（如拖延）背后可能有深层的情绪问题
4. **文化差异**: "两分钟法则"在集体主义文化中可能需要调整

**跨域映射**:

| 领域 | 对应概念 |
|-----|---------|
| 产品设计 | 用户习惯设计（Hook模型：触发→行动→多变的酬赏→投入） |
| 组织管理 | 组织文化塑造（Culture = Behavior + Systems） |
| 投资领域 | 复利思维（Compound Interest） |
| 软件开发 | 持续集成（微小改进持续合并） |
| 健身领域 | 渐进式超负荷（Progressive Overload） |

**知识连接**:

- 与《思考，快与慢》连接：习惯是系统1的自动化，减少认知负荷
- 与《心流》连接：好习惯创造条件，让心流更容易发生
- 与《认知天性》连接：间隔重复是巩固习惯的科学方法
- 与《原则》连接：系统思维是达利欧和克利尔的共同底层逻辑

**行动触发**:

读完这本书，应该做什么不同的事？

1. **身份声明**: 今天开始，用"我是[某种人]"替代"我想[做某事]"
2. **习惯叠加**: 在[现有习惯]之后，我将[新习惯]
3. **环境设计**: 把好习惯的提示放在显眼处，把坏习惯的提示藏起来
4. **两分钟法则**: 任何新习惯先压缩到2分钟内完成
5. **永不中断**: 追踪习惯，错过一次后立刻恢复
