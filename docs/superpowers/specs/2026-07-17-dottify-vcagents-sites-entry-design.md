# Dottify 与 VCagents Sites 入口设计

**日期：** 2026-07-17  
**状态：** 已确认

## 目标

在个人网站现有“工具”区域增加 Dottify 与 VCagents 两张项目卡片。卡片直接打开各自公开可访问的 Sites 托管地址，让访客无需登录即可体验项目。

## 方案

### Dottify

- 保留现有 Vercel 部署作为带登录、数据库和后台任务的全功能版本。
- 为 Sites 提供公开的浏览器本地演示版，复用现有产品界面与核心论点拆解体验。
- 演示数据保存在浏览器本地，不接入正式数据库、登录或后台人工智能任务。
- Sites 页面明确标注“演示版”，避免访客误以为本地数据会同步到正式产品。

### VCagents

- 复用现有 Sites 项目和公开地址，不创建重复站点。
- 保持现有浏览器本地存储模式，让访客可以直接切换投资人与项目方角色并体验匹配流程。
- 重新构建并验证当前仓库版本；只有在内容变化时才发布新版本。

### 个人网站入口

- 复用 `quartz/components/data/tools.ts` 和现有 `jvc-tool-card` 样式，不新增卡片系统或依赖。
- 在现有工具列表中加入 Dottify 与 VCagents，卡片链接改为各自 Sites 地址。
- 链接在新窗口打开，并保留现有安全属性。
- 卡片文案说明项目用途和“Live Site”属性，不暴露私有 GitHub 仓库地址。

## 非目标

- 不把两个应用代码合并进博客仓库。
- 不为项目新增自定义域名、账号体系或服务端基础设施。
- 不重做个人网站首页视觉，也不修改现有三段首页结构。
- 不把 Dottify 的正式后端迁移到 Sites。

## 发布与访问

- Dottify Sites 与 VCagents Sites 均为公开访问。
- 个人网站仍通过 `v4` 分支和 GitHub Pages 发布。
- 所有发布改动在隔离工作区完成，只提交本任务涉及的文件。

## 完成标准

1. Dottify Sites 匿名访问返回成功页面，核心演示交互可用。
2. VCagents Sites 匿名访问返回成功页面，角色切换与本地演示流程可用。
3. 个人网站首页出现两张项目卡片，分别指向正确的 Sites 地址。
4. 桌面与移动端卡片布局无溢出、裁切或不可点击问题。
5. GitHub Pages 发布成功，线上首页和两个外链均通过实际访问验证。
