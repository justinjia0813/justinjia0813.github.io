# v2.0 三模块终端点缀设计

## 目标

保留 v2.0 首页的“文章 / 工具 / 社区”三模块结构与米白编辑部版式，同时吸收合并请求 #19 的终端配色、等宽字体和命令行细节。首页打开后直接展示内容，不使用全屏启动层。

## 页面结构

首页结构保持不变：

1. 顶部身份区：`justin@universe ~ zsh`、站点标题、副标题、装饰分隔线和三项锚点导航。
2. 文章模块：继续从已发布文章中动态读取，按日期倒序展示。
3. 工具模块：只展示 `jvc-analyst`、`digital-person-skill`、`oh-my-waist`。
4. 社区模块：保留研究、分析、联系信息和引用。

## 视觉规则

- 保留米白背景、现有内容宽度、留白和三模块纵向节奏。
- 命令提示、导航序号和链接使用 #19 的橙色；终端提示和装饰分隔线使用绿色。
- 命令提示、日期、工具语言等辅助信息使用等宽字体。
- 文章卡和工具卡使用细边框、轻微悬浮位移和终端色高亮。
- 标题和正文继续使用现有中文衬线字体，避免全站变成代码界面。
- 手机端保持单列，不允许横向溢出；保留清晰的键盘焦点样式。

## 实现范围

主要修改 `quartz/styles/custom.scss`。如现有首页类名足够，不修改组件结构，不增加脚本、依赖或新的交互状态。文章页和列表页样式保持不变。

## 验证

- 自动检查首页仍包含 `articles`、`tools`、`community` 三个区块。
- 自动检查工具列表恰好三项。
- 运行全部测试、类型检查、格式检查和 Quartz 构建。
- 在本地浏览器检查桌面和 375 像素宽手机布局，确认三模块可见、无横向溢出、无浏览器错误。

## 不做

- 不恢复 Press Enter 启动层。
- 不改变文章数据、工具链接或社区文案。
- 不推送远端，直到本地预览获得确认。
