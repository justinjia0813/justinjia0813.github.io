# 科学智能基础设施文章写作与发布计划

1. 检索 DeepSeek 官方定价、开源和部署资料，以及科学智能全栈产品、私有化或本地部署的一手资料。
2. 按设计稿写入 `content/blogs/克制，是人工智能公司最大的商业野心.md`，使用实际发布日期且不设置草稿状态。
3. 区分官方事实、公司主张与作者判断，文末列出实际使用的一手资料和核验日期。
4. 运行 Markdown 格式检查、`npm test` 和 `npm run quartz -- build`。
5. 在本地桌面与手机视口检查标题、日期、目录、参考资料、横向溢出和浏览器警告。
6. 仅提交设计、计划和正文，推送分支、创建 PR 并合并至 `v4`。
7. 等待 GitHub Pages 部署成功，再检查公网文章和首页均返回 HTTP 200，并进行线上桌面/手机浏览器复核。
