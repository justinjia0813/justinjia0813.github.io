# 《讲清楚，然后做到极致》写作与发布计划

## 目标

将已确认的创始人判断框架写成正式博客文章，并发布到个人网站。

## 文件范围

- 参考：`docs/superpowers/specs/2026-07-18-founder-clarity-execution-article-design.md`
- 新增：`content/blogs/讲清楚，然后做到极致.md`
- 不修改网站组件、样式或其他文章。

## 执行

1. 使用 Kimi 官方发布、Arena 官方榜单和杨植麟公开访谈固定案例边界。
2. 按“案例—公式—拆解—四象限—飞轮—投资应用—边界”完成正文。
3. 检查首次出现的英文缩写、事实与推断、发布日期和参考链接。
4. 运行格式检查、测试和 Quartz 构建，并检查桌面端与移动端页面。
5. 仅提交设计、计划和目标文章，推送分支并合并到 `v4`。
6. 等待 GitHub Pages 部署完成，核对线上文章与首页入口。

## 完成标准

- 文章公开可访问，日期显示为 2026 年 7 月 18 日；
- K3 被表述为取得强烈早期反响，而非已经验证的长期商业成功；
- 正文明确给出乘法公式、四象限、正反馈飞轮、观察方法和误判边界；
- 本地测试与构建通过，线上文章和首页返回正常。
